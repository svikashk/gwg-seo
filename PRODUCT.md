# Product requirements

Give site owners a practical technical audit and a way to investigate their
search data. Offer a terminal command, an importable Node.js API, and a local
MCP server from one npm package. Agents get one small skill for choosing and
interpreting reports.

Runs belong to the user: settings, Google credentials, snapshots, and imported
files stay on their machine. There is no mandatory hosted service or telemetry.
Provider requests are explicit and paid services require their own credentials.

Explain observations and their limitations. Missing data is not zero; a
canonical or noindex declaration is not automatically a defect. Recommendations
must identify a concrete verification step. Do not promise rankings or revenue.

Installation must work from a packed archive outside the repository. Report
schemas, machine-readable errors, deterministic ordering, and resource limits
are part of the public API. Documentation lists implemented capabilities and
remaining work separately.
